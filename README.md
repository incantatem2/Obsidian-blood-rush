
# Blood Rush

A decorative dark theme inspired by the "Embiggen" layout for insanejournal, see: [link to the layout](https://tessisamess.insanejournal.com/30234.html)

Uploaded with permission from Tess, the original dev of Embiggen.


![screenshot](images/bloodrush-screenshot.jpg)


## Installation

1. Open Obsidian and go to **Settings > Appearance**.
2. Next to **Themes**, select **Manage**.
3. Search for "Blood Rush", then select **Install and use**.

To install by hand, download `manifest.json` and `theme.css` from the [latest release](https://github.com/incantatem2/Obsidian-blood-rush/releases/latest). Put both files in a folder named `Blood Rush` inside `.obsidian/themes/` in your vault. Then choose the theme under **Settings > Appearance > Themes**.
